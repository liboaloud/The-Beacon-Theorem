# The-Beacon-Theorem
The Beacon Theorem is divided into three parts that explain different concepts of the beacon pyramid.


# The Beacon Theorem
Main Formulas: 
b_l = (2h + L)(2h + W)
b = Σ_{h = 0}^{m} (2h + L)(2h + W) - β

The Beacon Theorem consists of 2 main formulas. A formula that calculates the area of a beacon layer measured in blocks², and another formula that calculates the number of blocks needed to build a beacon pyramid which is by summing up the areas of the layer starting from Layer 0 which is the area of the maximum beacon blocks adding up to a desired final layer which can be any natural number greater than 0.
